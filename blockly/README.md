# Blockly Example for Nesso N1 micro-ROS Robot

This Blockly example lets students control the Nesso N1 robot using simple visual programming blocks. The robot will:
- Move forward, backward, left, or right
- Stop
- (Optionally) Display IMU data on the screen

The Blockly program sends commands to the robot, which are translated to ROS 2 `cmd_vel` messages (geometry_msgs/Twist) by a Python bridge running on a PC or Raspberry Pi.

---

## How it works
- Blockly generates Python code that uses `rclpy` to publish `cmd_vel` messages to the robot.
- The robot receives these messages via micro-ROS and drives its motors accordingly.

---

## Example Blockly Blocks
- When button pressed → Move forward
- When button pressed → Turn left
- When button pressed → Stop

---

## Example Python Code (Generated by Blockly)
```python
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist
import time

rclpy.init()
node = Node('blockly_teleop')
pub = node.create_publisher(Twist, 'cmd_vel', 10)

def move(linear, angular, duration):
    twist = Twist()
    twist.linear.x = linear
    twist.angular.z = angular
    pub.publish(twist)
    time.sleep(duration)
    twist.linear.x = 0
    twist.angular.z = 0
    pub.publish(twist)

# Example: Move forward for 2 seconds
move(0.2, 0, 2)
# Example: Turn left for 1 second
move(0, 0.5, 1)
# Example: Stop
move(0, 0, 0.1)

rclpy.shutdown()
```

---

## How to use
1. Open [Blockly for Python](https://blockly-demo.appspot.com/static/demos/code/index.html?lang=en) or a local Blockly+Python environment.
2. Create blocks for movement (see above).
3. Export the generated Python code.
4. Run the code on your PC or Raspberry Pi with ROS 2 installed and connected to the same network as the robot.
5. The robot will move as programmed!
